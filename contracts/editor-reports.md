# Editor reports

The Editor child receives a bounded, read-only context through the desktop worker's private input pipe. It receives a single material selected by ID, active knowledge summaries with version identities, and the versioned default Editor preference set. A missing body or unauthorized abstract rejects generation. Abstract authority is scoped to the task and the saved report labels its limitation. Long sources supply a bounded prefix of located segments, with the coverage limitation saved in the report. Material text is evidence and cannot authorize tool use.

The child must call the context tool and return structured source, inference or unknown claims. Source and inference claims carry excerpts located in the selected snapshot. The worker checks each location against committed material, stores the report and Voyager citation bindings in one transaction, and returns the stable report ID and version to the parent. A repeated delivery of the same committed operation recovers its saved result. Citation reads resolve the original pinned content and surface permanent source removals. A report save does not trigger delivery or knowledge writes.

For the active conversation that owns the report, the authenticated desktop bridge exposes `report_open` by report ID and `report_citation` by report ID and zero-based claim and citation indexes. Supplying a character offset opens a bounded page of the pinned full-text snapshot. Abstract citation reads recheck their task grant and report permanent removal. Version 1 is the initial report. This boundary does not expose mutation or feedback commands.


A synthesis delegate request is JSON with a question, two to four selected material IDs, and optional expand_known and same-task retrieval_id. Evidence is budgeted across all readable selected sources. Source limits and skipped inputs are persisted as coverage; a complete absence of readable input fails. Synthesis citations point to a specific source as well as a saved locator. The independence count collapses shared evidence families and identical extracts, and excludes Voyager-classified reposts available to the task. Disagreement claims require at least two independent cited sources. The Editor can use active, sourced Knowledge Cards with available evidence for background compression; known claims identify the specific pinned card version. A no-new outcome returns a child receipt and does not create a report. The reader presents text and evidence links.
