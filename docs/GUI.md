# Horizon 桌面 GUI

## 窗口层级

- **顶栏**左侧提供左导航栏折叠入口。折叠后导航栏只显示图标。顶栏右侧是 Windows 窗口操作按钮。
- **左导航栏**提供各功能分区的入口。
- **工作区（workzone）**占据其余窗口空间，承载内容显示与交互。主面板（main_panel）常态显示当前分区的内容。侧面板（side_panel）从工作区右侧展开，渲染用户在主面板点开的术语、问题、HTML 或 PDF 等内容。展开侧面板或调节其宽度时，主面板随可用宽度缩放和重排。
- **悬浮窗口**在主面板内居中显示。打开时主面板背景变暗，其余元素不可操作。点击变暗区域时保留窗口。保存将内容写入当前草稿，取消或按 Esc 放弃窗口内的修改。切换主面板时自动关闭窗口，丢弃其中未保存的内容。

## 图书馆导航

| 入口 | 图标 | 主面板内容 |
|---|---|---|
| 百科 | 两个竖矩形斜向前后叠放 | 术语、问题和前沿 |
| 白板 | 横矩形与一支倾斜 45° 的笔 | 所有追踪中的百科条目链接 |

术语、问题和前沿共用百科入口和主面板。搜索栏左侧的「类型」下拉单选术语、问题或前沿，首次打开默认问题。搜索仅作用于当前类型；术语按名称、别名和释义搜索，问题按题干和解答搜索。

「状态」（全部／有效／存疑）和「追踪中」（全部／是／否）使用两个独立的单选下拉菜单，默认均为全部。切换类型时保留搜索词和追踪筛选。选前沿时，「状态」显示「不适用」并禁用，其原值在切回术语或问题时恢复。

术语和问题卡片的标题栏右侧以绿点表示有效、黄点表示存疑。前沿卡片省略圆点。三类卡片均以黄色边缘表示追踪中，未追踪使用默认边缘。标记只用于展示，悬停和读屏可获得适用于该类型的完整状态。用户在编辑表单修改状态及追踪选择。

「创建」按钮展开术语、问题和前沿三个选项，不受当前类型限制。选择后打开对应表单，创建成功后打开新条目详情。取消创建或从详情返回时，恢复发起操作的列表、搜索词及筛选条件。从正文或白板点击条目链接时，在侧面板直接打开目标详情，即使目标不符合当前筛选；返回时恢复来源视图。

术语移除「检索词」属性。旧值退出检索，别名继续作为术语的其他名称参与检索。

## 固定界面元素

桌面 GUI 的通用元素集中在 `desktop/src/gui/elements`。各面板组合这些组件。PDF 阅读器和报告预览负责各自的内容渲染，外围工具栏和操作控件使用固定组件。

| 元素 | 设计 |
|---|---|
| 单行输入框 | 深色圆角矩形，只显示一行。术语标题使用此组件。 |
| 多行输入框 | 与单行输入框同款。空白时等高，随输入或自动换行逐行增高，默认最多同时显示六行，超出后纵向滚动。打开已有内容时同样计算高度。术语释义使用此组件。 |
| 普通单选下拉 | 深色圆角矩形，左侧显示当前选项，右侧显示展开箭头。悬停项背景变浅，当前选中项右侧显示勾号。选中后立即更新并收起，Esc 收起并保留原值。 |
| 复选框 | 小号深色圆角方框，选中时以强调色填充并显示勾号，键盘聚焦时显示描边。每个选框和文字独占一行。选框靠左并在行内垂直居中，右侧文字可以换行，点击文字也能切换。 |
| 可折叠区块 | 整行可点击的深色圆角标题栏。左侧是标题，右侧箭头收起时向右、展开时向下。内容在标题栏下方，各区块沿用现有的默认展开状态。 |
| 文件选择 | 「选择文件」按钮打开系统文件选择窗口。文件名同行显示，空白时显示「未选择文件」。长名称截断并显示省略号，悬停可查看全名。 |
| 数据表格 | 深色表头，各行用细横线分隔。长文本允许换行，列宽仍不足时在表格区域内横向滚动。可点击的数据行悬停变浅。 |

### 可变下拉列表

术语的「别名」「来源」「关联术语」共用深色圆角下拉列表。收起时显示条目数量，空列表显示「未添加」。已有条目悬停时背景变浅，右端显示编辑和删除按钮。最末一项始终是新增项「+」。删除按钮直接从术语草稿移除条目，术语保存时沿用现有变更确认流程。

- **别名**在列表内编辑。点击「+」插入并激活一个空白项。按 Enter 或点击列表外确认当前值，按 Esc 恢复已有条目的原值或移除空白新项。
- **来源和关联术语**在悬浮窗口内编辑。「+」创建并激活空白项。关联术语选择已有术语。来源选择资料并可填写定位和摘录。填写了定位或摘录但未选资料时，保存会提示补选资料。
- 保存空内容时移除该项。取消编辑时丢弃新增项，恢复已有项的原值。悬浮窗口内保存的列表变更进入术语草稿，随术语统一提交。

## 修改确认

GUI 发起的图书馆变更在 GUI 展示确认卡片。用户确认某一选项后移除卡片按钮。卡片满 72 小时显示失效状态，失效卡片无法提交。审核和锁定规则见 [图书馆与图书管理员](adr/0002-library-and-librarian.md)。
