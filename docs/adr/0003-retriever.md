# 检索器由可独立调用的信息源组成

Voyager 的范围检索由服务按计划执行。检索器（Retriever）把主动检索能力交给会话中的 Agent，使它能根据已返回的结果调整检索式、调用顺序、轮次及结果处理。手动和自动任务默认调用全部已启用的信息源；探索者在会话中点名时，仅使用指定源，可临时调用已停用的源，保留原有开关设置。单个源失败时继续其余检索，并说明缺口。

每个信息源在 `retriever/sources/` 中独占一个目录，提供 Agent 可直接调用的检索工具、配置定义和介绍该源的 README.md。密钥值保存在用户本机。登记文件与连接测试脚本位于 `retriever/`。

首版包含 Tavily、OpenAlex，以及候选中所有对新用户开放、支持提交检索式且长期免费或提供持续免费额度的 API。盘点覆盖 Horizon 现有主动检索源及 GPT Researcher、Biomni 等工具使用的来源。商业或第三方 API 同样适用，第三方接口的卡片须标明实际提供商。仅有一次性试用赠金的接口和纯被动订阅排除。

检索器面板负责管理信息源。「刷新并测试连接」发现并测试所有源，每源一张卡片，展示名称、简介、配置、连接状态和启用开关。卡片按添加事件倒序排列，发现新源后滚动到顶部。新源首次测通时自动启用，包括补填密钥后首次成功的情形。此后刷新只更新连接状态，保留用户的配置和开关选择。目录被移除的源退出可调用列表。任务没有启用源且用户未指定来源时，提示去检索器启用来源。

百科前沿保留检索入口和历史，已有计划和结果仍可打开。新任务可以直接检索。左侧导航依次为资料库、百科、白板、检索器、自动任务。
