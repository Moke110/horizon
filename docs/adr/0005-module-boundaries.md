# 模块归属、角色权限与信息源凭据

按业务归属与公开工具划分模块，不要求每个模块独占数据库。登记和条目可以共用 SQLite；文件、脚本和密钥不必入库。缓存仅暂存任务产物，清空它不得破坏已入库的报道或原材料。

图书馆（`library`）涵盖资料库（`archive`）、百科（`pedia`）和写作参照（`writer-reference`）。参考材料保存为独立副本，而非指向原件的实时引用。用户偏好也属于写作参照。所有角色均可读取各数据模块的业务数据，均可写缓存；只有 `char-librarian` 可以写图书馆的三个子模块。工具校验格式与权限。本次不定义修改的具体流程、审批或交互机制。

信息源业务数据可读不等于凭据可读。API Key 仅存一份于本地配置，由本地执行端供已登记且经用户信任的信息源脚本使用。角色发起连接测试或检索时只传业务参数，只接收业务结果或脱敏错误；运行脚本的权限不包含读密钥或改写受信脚本的权限。

本决定更新 ADR-0002、0004 中的图书馆组成和读写入口，以及 ADR-0003 中的信息源边界。Voyager 已退役，应从产品中彻底清除，不作为 Retriever 的别名，也不并入定时任务。这里记录目标架构，不代表现有实现已清理。

## 界面、定时任务与 Harness

白板是 `horizon-electron` 查询百科中追踪条目的视图，不设独立数据集，也不另存链接清单。用户可通过 GUI 管理信息源和定时任务。角色中仅 `char-main` 可用专用工具维护定时任务和信息源的非敏感设置；`char-retriever` 可测试和执行检索，但不能修改脚本或凭据。密钥只从本地配置入口设置。

定时任务保存何时做、做什么。每次触发启动由 `char-main` 主持的任务会话，不直接调用子角色。无论手动还是定时任务，仅主代理可派发子代理和与用户交互。

`horizon-harness` 基于 Pi，负责模型调用、上下文管理、工具与技能加载、执行角色权限。允许哪些工具、谁可派发由 Horizon 角色声明决定；业务数据由相应工具校验。新增角色或替换信息源不应要求修改 Harness 核心。

## 代理间通信

Harness 通过 skill 和 tool 定义一套统一的 JSON 抽象，供主代理向子代理指派任务、子代理向主代理返回结果时使用。每个角色的 character-prompt 记录本角色可能用到的 JSON 抽象，并说明一次通信可发送一段 prompt 加 n 个 JSON 实例。相关工具脚本可以直接接收实例整体或其中一部分，无需代理把结构化数据复述为文本。传递实例不等于执行工具，也不授予接收者新的权限。

统一的是通信规则，不是业务字段。选材单、审稿意见等类型分别定义，skill 说明用法，tool 按同一份定义校验。角色 prompt 列明相关类型与收发场景，不复制字段表；新增业务类型无需修改 Harness 核心。

一次通信可不附实例，也可混合多个不同类型的实例。消息送达不等于任务交付完成，要求结构化交付时不能用文字代替。使用实例的一部分作为工具输入时，代理指定所需部分，工具直接取原值并保留 ID 和顺序。目标工具仍须校验输入与调用权限；不匹配则报错，不推测或补造字段。

PDF、报道 HTML 等文件通过引用传递，纪要与理由等短文本可直接随实例发送。未入库文件使用缓存引用，不冒用资料库永久 ID；文件清理后读取工具明确返回不可用。检索允许返回部分成果，同时列明缺口，区分未检索到与已找到但下载失败。主代理决定是否补检、采用现有成果或向用户说明限制。

Harness 自动把子代理返回关联到原指派，无需角色在 prompt 或业务实例里填写关联信息。业务实例可以单独转用于后续指派。

## 报道角色的交付边界

材料按用途而非格式区分。同一文件可以作为报道证据（`source-material`），也可以另存一份作为写作范例（`reference-material`）。作为写作参照不足以计入报道的实际覆盖材料。

Horizon 新写的报道在发布前必须由 Reviewer 审阅；Writer 完稿仍是缓存中的草稿。导入已有报道不要求经过此审稿步骤。本决定不规定修改轮次、审批或具体入库流程。

Editor 按篇向主代理提交选材单：主题、材料、选用理由及每份材料的纪要。同一材料可用于多篇报道；Writer 可读原材料。开写条件按篇判断，取代 ADR-0004 中整项任务检索结束才开写的规则。Writer 发现证据缺口时告知主代理，由主代理决定是否指派 Retriever 补检。

Reviewer 只向主代理反馈，不改稿、不改百科。事实错误、用词含混或偏离写作参照时，指出原句、依据与修改要求；解释清楚的新术语只需标出，释义冲突则并列双方依据，不预判谁错。发布后核对不自动执行：Librarian 只读主代理指定的已发布报道，返回匹配的问题或前沿、原文依据及相应解答或进展；无匹配时明确说明。此返回不等于百科已更新。
## Voyager 退役边界

移除 Voyager 的运行入口、后台任务、界面、配置项及专用代码，不保留兼容服务，不自动把旧任务转为定时任务。已登记到资料库或百科的内容保留原 ID 和引用。仅存在于 Voyager 私有存储中的内容不再加载，不因退役擅自删除用户磁盘上的原件。
